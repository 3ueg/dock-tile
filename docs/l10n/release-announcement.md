# Release-notes paragraphs for the localization release

Paste each paragraph into the GitHub release notes under a `### Now in your language` heading.
The website reads release notes from GitHub. Sparkle's update prompt shows no notes (the appcast
carries none), so existing users learn about the new languages from the in-app invitation instead.

**English.** Dock Tile now speaks 简体中文, 日本語, Deutsch, Русский and Français. These
translations were made by a machine and have not yet been checked by native speakers. If you read
one of these languages and something sounds wrong, you can fix it in five minutes in your browser —
no coding — at https://github.com/k97/dock-tile/blob/main/docs/l10n/README.md. Reviewers are
credited in the app.

**简体中文.** Dock Tile现已支持简体中文、日本語、Deutsch、Русский和Français。这些翻译由机器生成，尚未经过母语人士校对。校对者将在App中署名。如果你会其中一种语言，发现有读起来不对的地方，只需在浏览器里花五分钟就能修改，无需编程，指南见：https://github.com/k97/dock-tile/blob/main/docs/l10n/README.md

**日本語.** Dock Tileが简体中文、日本語、Deutsch、Русский、Françaisに対応しました。これらの翻訳は機械翻訳によるもので、ネイティブスピーカーによる確認はまだ行われていません。確認してくださった方のお名前はアプリ内に掲載します。いずれかの言語が読めて、おかしな表現に気づいたら、ブラウザで5分ほどで修正できます。コーディングは不要です。手順はこちら：https://github.com/k97/dock-tile/blob/main/docs/l10n/README.md

**Deutsch.** Dock Tile spricht jetzt 简体中文, 日本語, Deutsch, Русский und Français. Diese
Übersetzungen wurden maschinell erstellt und noch nicht muttersprachlich geprüft. Wenn du eine
dieser Sprachen sprichst und etwas falsch klingt, kannst du es in fünf Minuten im Browser
korrigieren – ganz ohne Programmierkenntnisse – unter
https://github.com/k97/dock-tile/blob/main/docs/l10n/README.md. Wer prüft, wird in der App genannt.

**Русский.** Dock Tile теперь доступен на языках 简体中文, 日本語, Deutsch, Русский и Français.
Эти переводы выполнены машиной и еще не проверены носителями языка. Если вы владеете одним из
этих языков и что-то звучит неправильно, вы можете исправить это за пять минут в браузере —
программировать не нужно — по адресу https://github.com/k97/dock-tile/blob/main/docs/l10n/README.md.
Имена проверяющих указываются в приложении.

**Français.** Dock Tile parle désormais 简体中文, 日本語, Deutsch, Русский et Français. Ces
traductions ont été réalisées automatiquement et n’ont pas encore été vérifiées par des locuteurs
natifs. Si vous lisez l’une de ces langues et que quelque chose vous semble
incorrect, vous pouvez le corriger en cinq minutes dans votre navigateur, sans aucune connaissance
en programmation, à l’adresse https://github.com/k97/dock-tile/blob/main/docs/l10n/README.md. Les
personnes qui relisent sont créditées dans l’app.
